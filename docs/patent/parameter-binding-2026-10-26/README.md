# 参数绑定核验与专利研发决策（2026-10-26）

后续已继续验证另一个窄问题：结构锚点、单参数观测与历史反例否决能减少部分错误，但与完整非图强基线等价，仍存在共同失效。[两轮结果与继续决策](../selector-applicability-2026-10-26/README.md)。下文保留原假设核验记录。

本轮完成源码检查、真实生产组件的隔离诊断、一个 HTTP 请求参数缺陷修复，以及图／非图防护的等价性对照。结论：**上一轮提出的“同值参数全部被错误泛化”没有在当前复用器中复现；本轮尚无可主张的新专利核心。**

这不是对所有未来方案的否定，而是对本轮实际实现和证据的判断。没有因图谱名称而升级交底，也没有将构造例写成真实站故障。

## 已确认的三个不同事实

1. **原假设未成立于本轮范围。** 当前复用器按参数位置与操作类型更新，不按数值全局替换。8 组同值／固定请求检查通过；不推断未覆盖的所有输入永远安全。
2. **真实传输缺陷已修复。** 原 HTTP 执行器向 HTTPX 传入空或非空 `params`，会覆盖 URL 原有查询串。已改为按键合并一次，并对最终实际 URL 执行策略及 robots 检查；重定向不重复注入原参数。这是常规正确性修复，不算新发明。
3. **另一个复用适用性风险可复现。** 在人工构造的栏目变更页面上，旧选择器仍指向推荐区，3 种选择器形式都得到非空错误结果且实际 QA 判 PASS。它不是数值错替，也不是已观察到的真实网站事故。

## 知识图谱有没有带来额外改进

本轮只实现了一个最小图表示对照：未证明查询变化后的适用性，就要求重新分析。它与简单查询条件判断逐项相同：挡住 3 个错误转移，同时拒绝 2 个本可正确复用的转移，只保留 1 个安全转移。

因此，只能证明该保守门槛在这组构造例中降低了错误接受，代价是覆盖下降；**没有证明图谱有额外效果**，也没有证明所有图谱方法无价值。该门槛没有接入生产记忆复用，以免无依据地改变正常复用覆盖。
