## E1：候选原型的公平先导

命令：

```powershell
D:\conda_envs\mytorch\python.exe scripts\benchmark_memory_applicability.py --output runtime\experiments\patent-memory-20261019\pilot.json
```

完整结果：[pilot.json](../../../runtime/experiments/patent-memory-20261019/pilot.json)。9个受控情形，每个10页，5种策略，包含选择记录、核验结果、成本和逐页决定。脚本实际解析HTML；正确正文和来源真值只在评分阶段读取。

各策略共享既有候选库 `#content`、`#article`、`[itemprop=articleBody]`，共享历史验证结果与非文本观测。额外核验检查的是公开schema.org/Article容器及其headline与列表标题的对应关系。它是受控页面可执行的来源合同，不能推广为任意网站正文正确性的oracle。

预算单位是一页快照的一次额外适用性核验，上限为1或2。各组均已获得全部10页，公共DOM解析和候选观察成本单列。本轮没有HTTP和模型调用，因此没有HTTP节省、token节省或模型自主修复成功率结果。

五个策略为：直接复用；TTL到期后前缀核验；路由分层核验；完整候选依赖观测变化后的逐URL局部核验；候选的观测差异选页与最小反例作用域。第四个是本轮实现的保守强工程基线，不是PlanFence、TRACE或任何论文原实现的复现。更强的抽象依赖/模板证书共享基线仍需补充。

### 所有情形的结果

三元组为“正确可用 / 误复用 / 保守拒用”，分母均为10页；临时不可用另列，不能算进正确或删掉。

| 情形 | 候选 | 逐URL局部复验强基线 | 判断 |
|---|---|---|---|
| 无关DOM编辑 | 10 / 0 / 0 | 10 / 0 / 0 | 平 |
| 全模板换正文容器 | 10 / 0 / 0 | 2 / 0 / 8 | 候选占优，但TTL/前缀也达到10/0/0，并非候选独有收益 |
| 同路由尾部8+2变体 | 10 / 0 / 0 | 10 / 0 / 0 | 平；直接复用/前缀/路由均8正确、2误复用 |
| 同路由前缀变体 | 10 / 0 / 0 | 10 / 0 / 0 | 平；前缀替换过度推广，产生8误复用 |
| 一次临时503 | 9 / 0 / 0，另1不可用 | 相同 | 平；没有测试持久状态和恢复序列 |
| B=1，两个新观测族 | 9 / 1 / 0 | 9 / 0 / 1 | 强基线占优，候选错误泛化 |
| B=1，未观察的同形来源反例 | 9 / 1 / 0 | 9 / 0 / 1 | 强基线占优，候选观测不足 |
| B=2，已观察同形反例 | 9 / 0 / 1 | 9 / 0 / 1 | 平，反例阻止该范围泛化 |
| 候选库无正确修复规则 | 8 / 0 / 2 | 8 / 0 / 2 | 平，均保留未知，未获得虚构修复 |

结果为6平、1候选占优、2强基线占优。这些情形不是独立随机试验，不能用“1/9胜率”或虚构显著性概括。现有证据不支持“候选整体优于强局部复验”，也不支持直接把最小特征作用域写成已验证的专利优点。

### 为什么负结果有决策价值

相同路由不足以认定相同模板；非文本结构摘要相同也不足以认定相同字段来源。在预算内没有观察到能区分两者的证据时，两个环境可能向策略提供完全相同的输入与探测结果，却要求不同的复用决定。此时无法无条件同时保证零误复用和全部放行；必须增加有效观测、收紧范围或返回待核验。

因此下一版不能只把scope条件写得更少、把复用覆盖率写得更高。需研究哪些额外证据能分离真实反例、费用是多少，并在同信息基线下比较。故意漏掉强基线的候选依赖、让候选读取真值或免费预读网页，均不构成可信优势。

## E2：下一版必须补齐的优势证据

| 待验证命题 | 公平对照与消融 | 通过依据 | 不能采用的替代说法 |
|---|---|---|---|
| 区分式选证据优于普通代表页覆盖 | 相同候选、预算与合同；随机、前缀、结构变体覆盖、差异选页 | 固定误复用约束下，更多可用规则或更少核验；在冻结新变体上成立 | 只赢“不更新记忆”的弱基线 |
| 反例限制范围减少错误泛化 | 同样选页；有/无反例约束、逐URL与抽象依赖范围 | 未见同形/同路由变体中错误减少，且拒用和额外成本完整报告 | 省略拒用或把未知标成PASS |
| 故障原因限定失效传播 | 整工作流停用、异常码分通道、证据限定通道 | 临时故障不永久损坏规则，真实规则失败不继续复用；恢复条件可回放 | 一个503被正确分类就声称因果归因完成 |
| 见证保护集阻止修复回退 | 随机/最近失败/变体覆盖/候选保护集 | 同预算或同存储量下，既修复失败又保留原成功规则 | 只检查修复目标页面 |

研发前冻结版本序列与预算，记录各探测的可见信息、实际费用和终止原因。先导集用于发现bug和开发，不能再次当作独立确认集。真实网页检验可从允许取得的历史快照开始，后续再安排在线访问；每份快照记录获取日期、来源和hash，人工标注真实正文来源与字段缺失，不能只标“非空”。

不预设成功幅度。建议的继续门槛是：在相同可观察信息和预算下，相比强基线不增加误复用，在多个冻结变化族中减少拒用或总核验成本；若存在安全/可用性取舍，应明确该取舍而不称全面优越。实验支持技术效果，但不独立证明创造性。
