# 任务常量适用性验证：工程有效，但尚无新增专利核心

日期：2026-10-26。承接[原假设核验](../parameter-binding-2026-10-26/README.md)。本轮完成两次隔离迭代：单参数观测＋新页核对，以及历史反例否决＋新页核对。使用真实生产组件，页面全部为人工构造；不代表真实网站故障率。

**结论：相比无检查复用，可以阻止部分误复用并保留部分正常复用；但候选与同信息的常规非图强基线逐项等价，而且仍有共同失效。当前不建议以此作为一件新专利的核心。**

第二轮固定 14 个机制族 × 3 个数值变体，共 42 个转移。原复用正确接受 15 个、错误接受 27 个；历史反例否决正确接受 9 个、错误接受 3 个、拒绝 6 个本可正确复用的转移。完整平表合取基线与图编码均相同。相较仅做新页双定位器检查，错误少放 3 个，但正常情况也少放 3 个，并增加校准观测；不能把它写成无代价的全面胜出。
