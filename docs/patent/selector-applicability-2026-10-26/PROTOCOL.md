# 任务常量适用性：预先固定的隔离验证协议

日期：2026-10-26。此协议先于本目录实验实现和正式运行写入；不属于外部注册。承接[上一轮负结果](../parameter-binding-2026-10-26/README.md)，不改生产复用器、用户记忆库或既有冻结证据。

## 研究问题与候选

研究问题：查询参数变化时，能否用源任务的选择节点及少量单参数对照，识别旧选择器的不适用，同时比“任何查询变化都拒用”保留更多本可正确复用的任务？

候选是研究用的“观测依赖＋目标页再核对”防护，不预设新颖，也不强制图数据库。源页面选中节点必须是同父、同标签的直接子节点；父节点必须有唯一 ID；以该父 ID 与子标签生成第二定位器。它只是假设性的结构延续锚点，**不是自动取得的任务语义真值**。

采样合同：源 URL 两次、分别只改变一个参数的三个对照 URL、新任务 URL 一次，共六份模拟响应。每份响应都经项目真实 HTTP 执行器抽取与 QA。单参数对照中，旧选择器与锚点不一致，仅记为“在这些观测中不适用”；一致不能证明全局独立。目标页必须再核对，不能仅凭历史未见依赖放行。

## 固定的对照

| 方法 | 可用信息及决策 |
| --- | --- |
| 当前复用器 | 实际 `build_reused_crawl` 构建结果；不新增准入检查。 |
| 查询完全相同门槛 | 仅查询相同放行。它不检查同查询下的页面漂移。 |
| 数值共现检查 | 被改变参数的旧值出现在选择器文本就拒用；用于检查共现与依赖混淆，不充当强基线。 |
| 观测依赖缓存 | 由单参数对照记录旧选择器／结构锚点不一致的参数；新请求改变这些参数时拒用。依赖不完整，不称为完整动态污点跟踪。 |
| 全部查询依赖缓存 | 没有可靠独立性证明就将全部查询键视为依赖；等价于保守查询门槛，不使用评分标签补齐依赖。 |
| 目标页双定位器一致性 | 源页面产生的结构锚点与旧选择器在目标页选中相同非空节点才放行；无额外单参数探测。它是多定位器思想的有限参考实现，不声称复现论文完整加权算法。 |
| 观测证据防护（平表／图编码） | 源任务重复定位一致、单参数对照齐备、锚点在各观测可唯一定位，并在目标页与旧选择器一致才放行；平表与图使用完全相同的事实。 |

不实现“给评分器真值的完整依赖缓存”冒充可部署基线。平表、图编码及强一致性对照均不能读取预期栏目或正确 URL 集合。只评估准入，不自动修复选择器，不把重分析视为成功采集。

## 固定场景与变体

以下 12 个机制族，各使用旧数值 10／42／73 三个变体，共 36 个诊断转移；变体不是独立网站。源栏目、页大小及跟踪参数故意同值，单参数探测值与最终请求值不同。

1. 通用主区选择器，栏目改变，应可复用。
2. 固定 data 属性，旧栏目移到推荐区，不应复用。
3. 固定 class，旧栏目移到推荐区，不应复用。
4. 编码后的固定值，不应复用；检查纯数值共现漏检。
5. 与参数同值但固定的布局常量，应可复用。
6. 不同区域文本相同、节点／链接不同，不应以文本相同放行。
7. XPath union 中含旧任务常量，不应复用。
8. 仅无关 tracking 变化，固定栏目选择器仍可复用。
9. 单参数对照均正常，只有两个参数共同改变才使规则失效，防止把未观察到依赖当成独立。
10. 查询相同、页面区域发生漂移，检查查询门槛的盲区。
11. 旧锚点 ID 被分配给非目标区域，检查两个定位器共同出错。
12. 无唯一父 ID，旧选择器仍正确；按候选合同应返回不确定并拒用，报告覆盖代价。

场景 11 是必要的反例，不因其导致候选失败而移除。所有源任务必须经实际 QA PASS、写入新建隔离 SQLite、读回一致后才进入复用。评分器只在所有准入决定产生后读取预期 URL 集合。

## 运行、计量和继续门槛

- 使用 `.example.test`、MockTransport，并阻断实际 DNS／TCP；不采集新闻站，不重试此前 robots 拒绝，不临时放宽安全配置。
- 每例保存源输入、逐份 HTML、模拟请求、QA 状态、结果哈希、观测与决定。保存算法、协议、运行器及涉及生产源码的 SHA256，运行前后检查。
- 共同证据池的实际生成费用为每例六次模拟 HTTP。各方法的最小页面需求另列；不能因为共享证据而声称普通复用也需要五次校准，不能把重复计算的准入决定当独立端到端性能实验。
- 同时报正确接受、错误接受、安全拒用、总拒用；按机制族列出失败。计数只用于受控机制检查，不估计线上发生率或统计显著性，不将 QA PASS 当作语义真值。
- 若候选只胜过查询门槛，而与目标页强对照逐项相同，不主张新增机制优势；若图／平表相同，不主张图谱收益；若锚点失效仍会误接受，明确安全边界，不部署生产。
